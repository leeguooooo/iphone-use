开始

iphone-use

让 AI agent 操作你的真实 iPhone。在 Mac 上装好 iphone-use 之后，Claude Code、Codex 或任何 MCP 客户端都能把手机屏幕读成文字，在任意 App 里点击、输入、滑动，包括没有 API 的 App： 健康、银行、聊天软件，或者你正在测的 App。你可以实时看着它操作，随时把手机拿回来。

bash · 在插着 iPhone 的那台 Mac 上 
$ curl -fsSL https://raw.githubusercontent.com/leeguooooo/iphone-use/main/install.sh | sh

三步接上你的 agent

  1. 准备好手机：一台 macOS 15 以上的 Mac，装好 Xcode 并登录 Apple ID；一台 iOS 15 及以上的 iPhone，以及首次配置用的数据线。iOS 16 及以上需打开开发者模式（设置 → 隐私与安全性 → 开发者模式）。iOS 17 及以上可用免费账号；iOS 15/16 在 Xcode 26 及以后需要付费账号的 App Store Connect API key，见安装要求。把 iPhone 插上并解锁。
  2. 运行上面的安装命令。它会把手机配好，让 agent 打开「设置」读一遍屏幕给你看，在 Claude Code 和 Codex 里注册 MCP server（装了 Cursor、Claude Desktop 的话也一并注册），再用一次性链接在浏览器里打开控制页。缺什么会直接告诉你缺什么、怎么补。
    bash 
    $ iphone-use doctor   # 缺什么、怎么补
$ iphone-use try      # 无害的检查：打开设置、读屏、回桌面
  3. 直接跟 agent 说。在 Claude Code 或 Codex 里新开一个对话，说你想在手机上做什么。不用学命令， 随附的 skill 会教 agent 怎么操作。其他客户端见 MCP、HTTP API 与 skill。

完整的环境要求、插件、升级和第二台手机：见安装。

可以让它做什么

下面这些说法在手机上的任何 App 里都适用。agent 可以按名字打开 App，一次输入一长段文字，跨页读完整个列表。

❤️ 从 App 里读数据

打开健康，告诉我这周每天走了多少步。

屏幕以文字（无障碍树）的形式返回，不是像素。
💬 没有 API 的聊天 App

在微信里找到妈妈发的最新一条消息，念给我听。

点击、输入（中文也行）、滑动都通过手机上的一个小型 XCTest runner 完成。
🏦 长列表一直读到底

把这个银行流水页面的每一笔交易都抄下来，一直翻到底。

跨页读列表，并说明有没有读到底。禁止截屏的页面按元素操作。
📝 一次写进长文本

把这篇 2000 字的草稿写进备忘录，新建一条。

一次输入最长 2 万字。
🧪 测你自己的 App

在真机上跑一遍我们 App 的登录测试，告诉我哪一步失败了。

读日志和崩溃报告、录屏、安装测试包、模拟定位，都在同一套工具里。
🔁 做一次，以后一键重放

把刚才做的这些存成 flow，下次一次调用就能跑完。

存好的 flow 重放时不经过模型，不花 token。

不想开终端

🤖 让 agent 帮你装

把一段提示词贴给 Codex 或 Claude Code。它会跑安装脚本，遇到只能你做的步骤（比如在 iPhone 上点「信任」）就停下来等你，绝不向你要密码或验证码。
🖥️ 用浏览器操作

H.264 实时画面：单击是点击，拖动是滑动，用你自己的输入法打字。「流程」面板能把你的操作录下来。
📲 用另一台 iPhone 远程控制

扫码配对后看画面、点、滑、打字。被控手机可以自己跑控制服务，不需要电脑；自建一个 Cloudflare 中继，在外面用蜂窝网络也能连回来。
🤖 手机自己操作自己

在 iPhone 上的「助手」里说一句要做的事，它就在这台手机上自己去点，做完告诉你。不需要电脑，模型用你自己的密钥。
👀 实时看 agent 在做什么

支持 MCP Apps 的 agent 客户端能在侧边栏看到手机画面，也可以在浏览器或 iOS App 里看。

为什么用真实 iPhone

🔓 任何 App 都行，不需要 API

健康、银行和支付 App（包括禁止截屏的）、聊天 App、你自己在测的 App，用的都是手机上已有的登录状态。
📶 USB 或 Wi-Fi，老 iPhone 也行

第一次用数据线配好，之后可以通过加密隧道走 Wi-Fi 操作。支持 iOS 15 及以上，不用升级手机系统。
✅ 结果说实话

每个操作都说明是已执行、没发出去还是结果不确定，以及能不能安全重试。点到被遮住的元素会直接拒绝。
🖱️ 不打扰你的 Mac

不碰 Mac 的屏幕、光标和窗口焦点。agent 和人共用一台手机，同一时间只有一方在用。
ℹ️ 速度：维护者自己的实测
同一台 iPhone 13、USB 连接（2026 年 10 月）：iphone-use runner 读屏 0.08–0.135 秒，点击并等画面稳定 1.0 秒； agent-device 约 0.7 秒和 2.8–3.3 秒。走完整的 agent 接口，在 iPhone 17 Pro Max 上按标签点击并带回稳定后的变化约 1.9 秒。这些数字来自项目 README 中的自测，不是第三方评测。

底层怎么做的

每台手机在 Mac 上对应一个守护进程。它把屏幕读成无障碍树，通过装在 iPhone 上的自研 XCTest runner 发送点击和输入，并在画面稳定后才返回结果。

⚙️ 它怎么工作

守护进程、XCTest runner、USB 与 Wi-Fi 隧道、空闲释放、把手机交还给人。
🔌 MCP、HTTP API 与 skill

Claude Code、Codex、Cursor、VS Code、Claude Desktop、Gemini CLI、opencode、Windsurf 的配置。
🔁 Flow 录制与重放

经过审阅的按 App 脚本、官方 flow 源、测试套件和定时运行。
⚖️ 和其他方案对比

mobile-mcp、agent-device、Appium 和其他 iPhone MCP 服务，依据各自的 README。

常见问题速答

需要越狱吗？

不需要。需要安装签名过的 XCTest runner，iOS 16 及以上还需打开开发者模式，安装脚本会用你的 Xcode 开发团队来构建它。

哪些 agent 能用？

Claude Code、Codex、Cursor、Claude Desktop 以及其他 MCP 客户端，都通过随附的 MCP server 接入；脚本和其他 agent 可以调用 /agent/* 下的 HTTP 接口。

必须有 Mac 吗？

必须。守护进程运行在 macOS 15 以上、装了 Xcode 的 Mac 上。其他设备可以访问它的网页和接口，但手机本身由这台 Mac 托管。

免费吗？是开源的吗？

下载和使用都不收费。它采用 PolyForm Shield 1.0.0 源码可见许可，不是 OSI 认可的开源许可：允许符合条款的非竞争用途、修改和分发，禁止用它提供竞争产品或服务。
