隐私与安全

iphone-use 跑在你自己的 Mac 上，操作的是你自己的 iPhone。没有 iphone-use 账号，中间也没有开发者的服务器。本页说明数据留在哪里、agent 能做什么不能做什么，以及怎样安全地从外网连回手机。完整原文见 隐私政策和 遥测说明。

默认只在本机

  • 守护进程监听 127.0.0.1:44321 并要求密码。agent 用 bearer 令牌认证（IPHONE_USE_AGENT_TOKEN，没设时退回用密码），所有改变状态的请求还要带 X-Phone-Control: 1。
  • 手机上的 runner 只接受签过名的请求：令牌由 setup 在每次启动 runner 时生成，用 HMAC-SHA256 签方法、路径、请求体、时间戳和一次性随机数。令牌只留在 Mac 上（权限 0600），从不随请求发送，截获的请求既不能重放也不能篡改。
  • USB 和 CoreDevice 的 Wi-Fi 隧道只有这台 Mac 能用。签名不等于加密：iOS 15/16 的局域网中继，以及显式打开的 IPU_RUNNER_ALLOW_LAN=1 中继是明文 HTTP，同一 Wi-Fi 上的人能看到画面，但没法操作手机。
  • 能读你 Mac 用户文件的人也能读到令牌。请把守护进程的地址和密码当作凭据保管。

密码只在你手里

  • 遇到登录、锁屏密码、Face ID，agent 会停下来请你在手机上完成，绝不向你要密码或验证码。
  • 如果你用 bitwarden-use，phone_login 会在守护进程内部用你自己密码库里的条目填好 App 的登录表单。密码不会经过模型，返回结果只给出条目名和打码后的账号。
  • flow 的输入只对本次运行生效，不会写回 flow 文件。输入里不能放凭据、验证码或私人内容。

agent 绕不过去的限制

手机主人在守护进程的环境变量里设置，不管 agent 的提示词怎么写都有效。

  • IPHONE_USE_BLOCKED_APPS（例如 Wallet, Passwords）：agent 不能打开、安装或卸载这些 App。
  • IPHONE_USE_MAX_ACTIONS：限制每个任务的操作步数。
  • 被拒绝时返回 403 和 outcome:"not_sent"：没有任何操作到达手机。

详见 Owner limits and the activity feed。

它做了什么你看得见

  • 网页会在实时画面上用大白话显示每一步，例如「点按“无线局域网”」。输入的文字不会被记录，只记字数。
  • 每个 /agent/* 请求的耗时记在 ~/.iphone-use/agent-timing.jsonl，只有路由、使用者和耗时，从不记请求或屏幕内容。
  • 一台手机同一时间只有一个使用者。你在操作时，agent 会等着，或被告知手机在谁手里。

遥测：关闭

✅ 当前版本不发送任何使用数据
守护进程里有匿名使用计数的代码，但发行版不带项目令牌，所以除非你自己设置 IPHONE_USE_TELEMETRY_TOKEN， 它什么也不发。如果将来某个版本打开它，会在 隐私政策和 telemetry.md 里写明。

即使打开，每条事件也只包含调用了哪个 agent 接口、是否成功、固定列表里的失败类别、耗时、守护进程的版本和平台，以及一个随机安装 ID；绝不发送输入或读到的文字、元素标签、截图或视频、App bundle id、手机标识或名称、文件路径。下面任意一个都能彻底关掉它：

bash 
IPHONE_USE_TELEMETRY=0
DO_NOT_TRACK=1

iOS App

iOS App（Phone Use Remote）不收集任何数据，开发者也没有为它运行服务器：没有账号，没有统计、崩溃上报、广告或追踪 SDK。它只和你输入或扫码得到的那台 Mac 通信。Mac 地址存在 App 偏好设置里，密码或配对令牌存在 iOS 钥匙串里；相机只用来扫配对二维码，本地网络权限只用来连那台 Mac。在 App 设置里点「忘记这台 Mac」会删掉保存的密码和配对令牌。

从外网连回来

  • 通过带鉴权的 HTTPS 反向代理，或 Tailscale 这类可信 VPN 访问 44321 端口；绝不要把 runner 的端口暴露出去。
  • 守护进程绑定 0.0.0.0 时必须设密码。不要在不可信的网络上这么做。
  • iphone-use-mcp --listen 监听回环地址时只有本机能连；监听其他地址必须设置 IPHONE_USE_MCP_TOKEN。
  • 使用者租约只是协作会话之间的协调，不是安全边界。开放访问时别把支付 App、私人聊天或二次验证页面开着；不用时停掉 LaunchAgent。
